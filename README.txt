MANSUR CLICKER
==============

Запуск: откройте index.html в современном браузере.

ВАЖНО: текущая сборка сохраняет ссылки на пользовательские ресурсы:
  characters/mansur.png
  characters/bobik.png
  characters/slava.png
  characters/vita.png
  characters/yasen.png
  characters/genka.png

Эти изображения не были приложены в исходном архиве/вложениях, поэтому их нужно положить в папку characters/.

Аудио:
  Папка audio/ предназначена для пользовательских звуков. Игровые точки подключения находятся в playSfx() в script.js.

Ключевые системы:
  - новый единый state/save вместо двух конфликтующих реализаций;
  - комбо + критические клики + крит-урон;
  - пассивный доход;
  - 8 улучшений с масштабированием стоимости;
  - уровни и XP;
  - персонажи с множителями;
  - задания;
  - достижения;
  - ежедневная награда и серия;
  - случайные ивенты;
  - престиж за кристаллы;
  - офлайн-награда;
  - экспорт/импорт/сброс сохранения;
  - мобильная навигация и адаптивный интерфейс;
  - клавиши Space/Enter для клика.
